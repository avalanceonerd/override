# Weibo LPX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a self-contained Loon Weibo LPX which retains Kelee's present coverage and prevents genuine comments from being classified as feed advertising.

**Architecture:** The LPX retains Kelee's Rule, Rewrite, MITM, and endpoint patterns while every script entry points to one repository-hosted JavaScript processor. That processor dispatches by endpoint and uses separate `isFeedAd` and `isCommentAd` classification functions. Node's built-in test runner invokes the script with mocked Loon globals against HAR-derived fixtures.

**Tech Stack:** Loon LPX, ES2020, Node.js `node:test`, `node:assert`, and `node:vm`.

## Global Constraints

- Retain the Kelee 2026-06-01 LPX endpoint coverage and current UI-cleanup behavior.
- Never use feed fields, especially `readtimetype: "adMblog"`, to discard comments.
- Filter pseudo-comments only by exact system account name, never by a partial match such as `微博`.
- Keep comment pagination and count fields unchanged.
- Use only `https://raw.githubusercontent.com/avalanceonerd/override/main/weibo/js/weibo-remove-ads.js` for runtime script loading.
